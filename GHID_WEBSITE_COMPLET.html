1. Pregătirea Mediului de Lucru

Înainte de a începe, asigură-te că ai tot ce îți trebuie pentru a dezvolta și publica website-ul.

⚠️ IMPORTANT: Acest ghid funcționează pe Windows, macOS și Linux. Pașii sunt identici, doar comenzile pot varia ușor.

Ce ai nevoie:

  • Un computer cu Windows 10+, macOS 10.15+, sau Linux
  • Conexiune la internet stabilă
  • Domeniul cumpărat (ex: partizanresort.com)
  • Email business (ex: contact@partizanresort.com)
  • Poze de calitate pentru website (min. 1920x1080px)
  • Informații despre business (prețuri, servicii, descrieri)
  • 2-3 ore de timp liber

Software necesar:

Tool Scop Link
Node.js Runtime pentru aplicația Next.js nodejs.org
Git Version control (opțional dar recomandat) git-scm.com
VS Code Editor de cod (recomandat) code.visualstudio.com
Cont Vercel Hosting GRATUIT pentru website vercel.com

2. Instalare Node.js și Instrumente

1 Descarcă Node.js

Mergi pe https://nodejs.org și descarcă versiunea LTS (Long Term Support) - versiunea cu cifre PARE (ex: 20.x.x, nu 21.x.x).

  • Windows: Descarcă .msi installer
  • macOS: Descarcă .pkg installer
  • Linux: Folosește package manager-ul tău (apt, yum, etc.)
2 Instalează Node.js

Rulează installer-ul descărcat și urmează pașii:

  1. Dublu-click pe fișierul descărcat
  2. Click Next → Accept → Next
  3. Asigură-te că este bifat "Automatically install necessary tools"
  4. Click Install și așteaptă 2-3 minute
  5. Click Finish
3 Verifică Instalarea

Deschide Command Prompt (Windows) sau Terminal (macOS/Linux) și scrie:

node --version

Ar trebui să vezi ceva de genul: v20.12.0

Apoi verifică npm:

npm --version

Ar trebui să vezi: 10.5.0 sau similar

✅ SUCCES! Dacă ai văzut version numbers, Node.js este instalat corect!
4 Instalează VS Code (Opțional)

Mergi pe https://code.visualstudio.com, descarcă și instalează VS Code pentru sistemul tău de operare.

După instalare, deschide VS Code și instalează extensia "ES7+ React/Redux/React-Native snippets" din Marketplace (Ctrl+Shift+X).

⚠️ ATENȚIE WINDOWS: După instalare, TREBUIE să închizi și redeschizi Command Prompt-ul ca să fie recunoscute comenzile!

3. Setup Proiect Local

Acum ai tot ce îți trebuie instalat. Hai să configurăm proiectul website-ului!

1 Creează un Folder pentru Proiect

Alege o locație pe computer unde să păstrezi proiectul. De exemplu:

  • Windows: C:\Users\Adrian\Projects\partizan-website
  • macOS: /Users/adrian/Projects/partizan-website
  • Linux: /home/adrian/Projects/partizan-website

Creează folder-ul manual sau prin command line:

mkdir partizan-website
cd partizan-website
2 Copiază Fișierele Proiectului

Am pregătit toate fișierele proiectului în folder-ul partizan-website. Copiază TOATĂ structura de foldere în locația ta:

  • package.json - Dependențele proiectului
  • src/ - Codul sursă al website-ului
  • public/ - Imagini și assets
  • tailwind.config.ts - Configurare stiluri
  • Toate celelalte fișiere din proiect
3 Instalează Dependențele

Deschide Command Prompt sau Terminal în folder-ul proiectului și rulează:

npm install

Acest proces va dura 2-5 minute și va descărca toate librăriile necesare (React, Next.js, Tailwind, etc.). Vei vedea un progress bar și multe linii de text.

⚠️ ATENȚIE: Dacă vezi WARN messages, nu-i bai! Doar ERROR messages sunt probleme.
4 Verifică Structura

După instalare, ar trebui să vezi un folder node_modules/ creat automat. Structura finală:

partizan-website/
├── node_modules/         (creat automat, MARE ~500MB)
├── public/
│   └── images/
├── src/
│   ├── app/
│   ├── components/
│   ├── data/
│   └── types/
├── package.json
├── next.config.js
├── tailwind.config.ts
└── README.md
✅ GATA! Proiectul este configurat local. Next step: testare!

5. Deployment pe Vercel

Vercel este platforma GRATUITĂ și SUPER RAPIDĂ pentru hosting Next.js. Zero configurare, SSL automat, CDN global inclus!

Metoda 1: Deploy prin GitHub (RECOMANDAT)

1 Creează Cont GitHub

Mergi pe https://github.com și creează un cont gratuit dacă nu ai deja.

  1. Click Sign up
  2. Introdu email, password, username
  3. Verifică email-ul primit
2 Creează Repository

După login, în GitHub:

  1. Click butonul verde "New" (stânga sus)
  2. Repository name: partizan-resort-website
  3. Lasă Public selectat
  4. NU bifa "Add README" (avem deja)
  5. Click Create repository
3 Push Codul pe GitHub

În terminal, în folder-ul proiectului, rulează comenzile de mai jos EXACT în ordinea asta:

git init
git add .
git commit -m "Initial commit - Partizan Resort Website"
git branch -M main
git remote add origin https://github.com/USERNAME/partizan-resort-website.git
git push -u origin main

ATENȚIE: Înlocuiește USERNAME cu username-ul tău GitHub!

La primul push, îți va cere username și password GitHub. Introdu-le.

✅ BRAVO! Codul este acum pe GitHub! Poți vedea repository-ul la github.com/USERNAME/partizan-resort-website
4 Creează Cont Vercel

Mergi pe https://vercel.com și:

  1. Click Sign Up
  2. Alege "Continue with GitHub"
  3. Autorizează Vercel să acceseze GitHub-ul tău
5 Importă Repository-ul

În dashboard-ul Vercel:

  1. Click "Add New..." → "Project"
  2. Vei vedea lista de repositories din GitHub
  3. Click Import pe partizan-resort-website
6 Configurare Deploy

Vercel detectează automat că e Next.js. Doar verifică:

  • Framework Preset: Next.js (auto-detectat)
  • Root Directory: ./ (lasă default)
  • Build Command: next build (auto)
  • Output Directory: .next (auto)

Click Deploy și așteaptă 1-2 minute!

🎉 FELICITĂRI! Website-ul este LIVE la un URL Vercel (ex: partizan-resort-website.vercel.app)! Vei primi link-ul la final de deployment.

Metoda 2: Deploy Direct prin CLI (Alternativă)

1 Instalează Vercel CLI

În terminal:

npm install -g vercel
2 Login în Vercel

Rulează:

vercel login

Alege metoda de autentificare (GitHub, Email, etc.) și urmează pașii.

3 Deploy Proiectul

În folder-ul proiectului, rulează:

vercel --prod

Răspunde la întrebări:

  • Set up and deploy? → Yes
  • Which scope? → Alege contul tău
  • Link to existing project? → No
  • Project name? → partizan-resort-website
  • Directory? → ./ (apasă Enter)

Deployment va rula automat!

6. Configurare Domeniu Custom

Acum website-ul este live la partizan-resort-website.vercel.app, dar vrei să-l conectezi la domeniul tău: partizanresort.com

1 Verifică Ownership-ul Domeniului

Asigură-te că ai acces la DNS settings pentru partizanresort.com. De obicei, îl gestionezi prin:

  • GoDaddy
  • Namecheap
  • Cloudflare
  • Google Domains
  • Sau orice alt registrar
2 Adaugă Domeniu în Vercel

În dashboard Vercel:

  1. Click pe proiectul partizan-resort-website
  2. Mergi la tab-ul Settings
  3. Click Domains (meniu stânga)
  4. În câmpul "Domain", scrie partizanresort.com
  5. Click Add
3 Copiază DNS Records

Vercel îți va arăta ce records DNS trebuie adăugate. De obicei:

Type Name Value
A @ 76.76.21.21
CNAME www cname.vercel-dns.com

ATENȚIE: Valorile exacte pot fi diferite! Copiază ce îți arată Vercel!

4 Configurează DNS la Registrar

Loghează-te în contul unde ai cumpărat domeniul și mergi la DNS Settings sau DNS Management.

Exemplu GoDaddy:

  1. Mergi la My Products
  2. Click pe DNS lângă domeniul tău
  3. Click Add Record
  4. Adaugă record-urile A și CNAME de la Vercel
  5. Click Save

Exemplu Cloudflare:

  1. Selectează domeniul partizanresort.com
  2. Mergi la tab-ul DNS
  3. Click Add record
  4. Completează Type, Name, Target conform Vercel
  5. Setează Proxy status la DNS only (cloud gri, NU portocaliu!)
  6. Click Save
⚠️ ATENȚIE CLOUDFLARE: Dacă folosești Cloudflare, OBLIGATORIU setează proxy la DNS only (cloud gri). Altfel, SSL-ul nu va funcționa corect!
5 Așteaptă Propagarea DNS

DNS changes pot dura între 5 minute și 48 ore pentru a se propaga global. De obicei, durează 15-30 minute.

Verifică status-ul în Vercel - când domeniul arată "Valid Configuration" și certificatul SSL e activ, ești gata!

🎉 SUCCES! Website-ul este acum accesibil la https://partizanresort.com cu SSL activ (lacăt verde în browser)!

9. Troubleshooting

Probleme Frecvente & Soluții

EROARE: npm: command not found

Cauză: Node.js nu este instalat corect sau PATH-ul nu e setat.

Soluție:

  1. Reinstalează Node.js de pe nodejs.org
  2. Restartează computerul
  3. Deschide un terminal NOU și verifică: node --version
EROARE: Error: Cannot find module 'next'

Cauză: Dependențele nu sunt instalate.

Soluție:

rm -rf node_modules package-lock.json
npm install
EROARE: Port 3000 is already in use

Cauză: Alt proces folosește portul 3000.

Soluție:

  • Windows: Deschide Task Manager → Termină procesul Node.js
  • macOS/Linux: lsof -ti:3000 | xargs kill -9

SAU rulează pe alt port:

PORT=3001 npm run dev
PROBLEMĂ: Domeniul nu se conectează la Vercel

Verificări:

  • DNS records sunt setate EXACT ca în Vercel?
  • Cloudflare proxy e setat la DNS only (cloud gri)?
  • Au trecut cel puțin 30 minute de la modificarea DNS?
  • Verifică propagarea: https://dnschecker.org
PROBLEMĂ: Imaginile nu se încarcă

Cauze posibile:

  • Path-ul e greșit (verifică că începe cu /images/)
  • Imaginea nu există în public/images/
  • Extensia fișierului e greșită (.jpg vs .jpeg)

Soluție: Verifică în browser DevTools (F12) → Console pentru erori 404.

PROBLEMĂ: Website încarcă încet

Soluții:

  • Comprimă imaginile cu https://tinypng.com
  • Convertește în WebP cu https://squoosh.app
  • Verifică că nu ai imagini mai mari de 500KB
  • Rulează Lighthouse audit pentru recomandări
