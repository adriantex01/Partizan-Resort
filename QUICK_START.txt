    PARTIZAN RESORT WEBSITE - QUICK START GUIDE
═══════════════════════════════════════════════════════════════════

📦 SETUP RAPID (5 minute)

1. Asigură-te că ai Node.js instalat:
   node --version
   (Dacă nu, instalează de la: https://nodejs.org)

2. Instalează dependențele:
   npm install

3. Rulează local pentru testare:
   npm run dev
   
   Deschide: http://localhost:3000

4. Pentru producție:
   npm run build
   npm start

═══════════════════════════════════════════════════════════════════
    DEPLOYMENT PE VERCEL (10 minute)
═══════════════════════════════════════════════════════════════════

METODA 1 - GitHub + Vercel (RECOMANDAT):

1. Push pe GitHub:
   git init
   git add .
   git commit -m "Initial commit"
   git remote add origin https://github.com/USERNAME/repo-name.git
   git push -u origin main

2. Conectează la Vercel:
   - Mergi pe https://vercel.com
   - Click "New Project"
   - Import repository-ul
   - Click "Deploy"

METODA 2 - Vercel CLI (Mai rapid):

1. npm install -g vercel
2. vercel login
3. vercel --prod
